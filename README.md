# Employee Salary and Attendance Management System

This is a console-based application developed in C++ to manage employee records, attendance, and salary calculations.

## 🚀 Features

- Add and view employee data
- Mark and view attendance
- Calculate monthly salary with:
  - Overtime pay
  - Bonus system
  - Tax deduction
- Save and load data using file handling

## 🛠️ Technologies Used

- C++
- File Handling (fstream)
- Structures

## 📊 Concepts Implemented

- Arrays
- Functions
- Structures
- Conditional Logic
- File I/O

## 🎯 Purpose

This project was created to improve programming logic and understand real-world problem solving using C++.
